- Pillow / `PIL` (verified operational for chart generation).

- **Missing Dependencies:** **NONE**. All libraries, files, and metadata are verified present.

### Identified Ambiguities:
- **ShuttleSet Contact Height Convention:** Discovered during forensic audit that `hit_height == "1.0"` denotes overhead/above net level, while `"2.0"` denotes below net tape (net shots). This has been formally resolved and documented in the pipeline audit.

### Technical Risks & Mitigations:
1. **Risk:** Over-correcting the CLEAR/DROP boundary might push ambiguous drops into SMASH or vice-versa.
   - *Mitigation:* `EXP02A_IMPLEMENTATION_PLAN.md` mandates strict monitoring of the `SMASH ↔ DROP` error boundary (ceiling: $\le 57$ validation errors).
2. **Risk:** Feature fusion corrupting non-target logits.
   - *Mitigation:* The `TargetedDropClearResidualGate` mathematically forces $\Delta L_c = 0$ for $c \in \{\text{SMASH}, \text{DRIVE}, \text{NET\_SHOT}\}$. Zero collateral damage is guaranteed.
3. **Risk:** Test-set leakage during hyperparameter selection.
   - *Mitigation:* The official test set ($N=2,001$) is omitted from the data directory. All evaluations occur exclusively on the validation split ($N=1,960$).
